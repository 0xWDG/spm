# Support

Use the following channel for the kind of help you need:

- Read the [README](README.md) for installation, commands, configuration, and known side effects.
- Open a [GitHub issue](https://github.com/0xWDG/spm/issues/new/choose) for a reproducible bug or a focused feature request.
- Follow [CONTRIBUTING.md](CONTRIBUTING.md) when proposing code or documentation changes.
- Report suspected vulnerabilities privately according to [SECURITY.md](SECURITY.md).

When asking for help, include the `spm` revision or release, macOS version, Swift version (`swift --version`), the command you ran, and the complete error output with sensitive values removed.
